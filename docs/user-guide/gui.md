# 視窗版（cvewatch-gui）

`cvewatch-gui.exe` 是與 TUI 功能同等的 Windows 視窗介面（不開主控台視窗），與 CLI、TUI 共用同一個加密資料庫與設定檔，可以同時開啟。

- **三個執行檔放在同一資料夾**：`cvewatch.exe`、`cvewatchw.exe`、`cvewatch-gui.exe`。視窗版的同步、匯入清冊與重新安裝排程都是以隱藏視窗執行同資料夾的 `cvewatch.exe`；找不到它時這些按鈕會停用（滑鼠停留時說明原因），其他功能照常
- 設定檔解析順序與 CLI 相同：`--config` → 環境變數 `CVEWATCH_CONFIG` → 使用者設定目錄。指定設定檔時，由視窗啟動的 sync、清冊匯入與排程重新安裝也使用同一個設定檔：

```powershell
.\cvewatch-gui.exe
.\cvewatch-gui.exe --config D:\cvewatch\cvewatch.toml
```

- 繁體中文使用 Windows 內建的微軟正黑體（找不到時依序改用正黑體 Light、細明體；都沒有時頂端顯示警告）
- 繪圖預設用 wgpu（DirectX 12），無法使用時自動改用 OpenGL；兩者都不行（部分遠端桌面或虛擬機）時會跳出訊息框，請改用 `cvewatch tui`

## 匯入清冊

拖放 .xlsx 或 .csv，或以檔案對話框選擇：

1. 先顯示預覽（等同 `cvewatch asset import <檔案> --dry-run`），資料庫尚未變更
2. 可勾選「將清冊中消失的資產標為退役」（`--prune`）；CSV 清冊可「選擇元件檔」（`--components`）與「選擇 IP 檔」（`--ips`），選擇後重新預覽。沒有選擇 IP 檔時保留既有資產的 IP，預覽顯示對應的提醒
3. 按「匯入」才寫入，之後自動比對並重新載入畫面；一次只接受一個 .xlsx 或 .csv

匯入預覽頂端會提醒：匯入以檔案內容覆寫資產欄位與清冊元件。在視窗中修改過資產後，請先「匯出清冊」、編輯匯出的檔案，再匯入（見[資產清冊](assets.md)）。

## 資產編修（資產畫面）

- 資產清單以編號、名稱、未處理命中數三欄列出（未處理數大於 0 時以紅字顯示）；詳情中的產品以目錄的顯示名稱呈現（例如「Proxmox VE 8.2.2」，滑鼠停留時顯示產品 key），類別以「代碼 名稱」顯示（例如「HW01 伺服器」），曝露度以「英文值（中文）」顯示（例如「internal（內部網路）」），清冊與 CLI 仍使用代碼與英文值；詳情另列機密性、完整性、可用性、資產價值與 ISMS 編號
- **元件依角色分組**：資產詳情與編輯對話框的元件區塊依產品目錄的角色分組，每組以粗體組名開頭、元件列在組名之下（詳情中各元件的版本歷史緊接在該元件之下）。組的順序固定為韌體、BIOS、BMC、作業系統、資料庫管理系統、網站服務系統、應用工具軟體、資通安全系統、一般套裝軟體、應用程式元件、其他，主機套件另成最後一組「套件」；沒有元件的組不顯示，同組內維持原本的元件順序。編輯對話框中「加入元件」新加入的元件直接出現在其角色的組內（游標仍移到它的版本欄），標為移除的元件留在原組。角色由目錄決定，可在 `catalog.d` 覆寫，下次開啟視窗即依新角色分組，不需重新匯入（見[資產清冊](assets.md#元件角色)）
- **新增資產／編輯**：對話框編輯資產欄位（標「*」者為必填；類別、曝露度、機密性、完整性、可用性為下拉選單，C/I/A 選「依類別（N）」時儲存子類別的範本值，資產價值即時顯示；ISMS 編號為選填文字欄位；編輯時可修改資產編號＝更名，規則同 `cvewatch asset rename`，欄位下方會提示舊清冊與已匯出的 VEX 不會對應到新編號）與元件（「加入元件」開啟產品選擇器，選擇產品後游標移到該元件的版本欄；只能選既有目錄產品，選擇器用法見下方）。驗證規則與清冊匯入相同，錯誤以介面用語（例如「必填」）紅字顯示在欄位下方，對話框不關閉；按「取消」不寫入。主機套件元件唯讀（由 `cvewatch asset import-packages` 管理）；未辨識產品可「改為…」目錄產品（沿用原版本字串）或刪除
- **識別與網路**（資產對話框的第三欄）：廠牌、型號、序號、財產編號、主機名稱與管理介面位址為選填文字欄位；IP 清單每列有「IP」「用途」與「移除」，按「新增 IP」加入空白列（游標移到新列的 IP 欄位），完全空白的列儲存時忽略。規則與清冊相同（見[資產清冊](assets.md#清冊欄位assets-工作表)）：錯誤顯示在對應欄位或 IP 列下方（例如「不是有效的 IPv4 或 IPv6 位址」「需以 http:// 或 https:// 開頭」），財產編號已被其他資產使用時在儲存前就標示「已被使用（已退役的 NAS-02）」。只修改 IP 時不需要重新比對
- **資產詳情的識別欄位**：列出廠牌、型號、序號、財產編號、主機名稱、管理介面位址與 IP（「位址（用途）」，依儲存順序），未填為「-」。管理介面位址顯示成連結，點擊後以預設瀏覽器開啟（http 與 https 都可以，這是自己輸入的位址；CVE 參考連結仍只開 https），狀態列顯示結果
- **搜尋框**（資產清單上方）：依資產編號、名稱、主機名稱、IP、序號與財產編號篩選，部分相符、不分大小寫；輸入完整 IP 時，寫法不同但位址相同的 IP 也找得到（`2001:DB8:0::1` 找得到 `2001:db8::1`）。可與「顯示已退役」「只顯示版本待補」同時使用；搜尋中各組一律展開，按「清除」或清空搜尋字後恢復原本的收合狀態。沒有符合的資產時清單顯示「沒有符合「…」的資產」
- **產品選擇器**（「加入元件」與未辨識產品的「改為…」共用）：開啟後游標在「搜尋產品」框，可直接輸入；搜尋比對顯示名稱、別名與廠商，不分大小寫並忽略空白與 `-_./`（`aoscx` 找得到 AOS-CX，`aruba` 也找得到），名稱或別名以搜尋字開頭者排在前面，同級依顯示名稱排序。一次最多列 12 項，其餘以「還有 N 項，再輸入文字縮小範圍」提示；沒有相符時顯示「沒有相符的產品」。↑↓ 移動反白、Enter 選擇反白項目、Esc 關閉且不變更。「改為…」的清單最上方是「保留」，接著是與原文相似的「建議」產品（與匯入報表相同，最多 3 個），再接搜尋結果；選擇後處置顯示「改為 <顯示名稱>」
- **退役…**＝標為退役（確認對話框標題「將 <資產編號> 標為退役」）：命中與處理紀錄保留、不再參與比對，可恢復。勾選「顯示已退役」後，已退役資產以灰字與「（已退役）」列出，可「恢復」或「永久刪除」
- **永久刪除**會一併移除該資產的元件、版本歷史、命中與處理紀錄，**無法復原**；需輸入完全相同的資產編號才能確認。請先執行 `cvewatch db backup` 備份資料庫
- 每次編修後（只更名時不需要）在背景執行 `cvewatch match`（狀態列顯示「比對中…」，視窗仍可操作），完成後重新載入；找不到 `cvewatch.exe` 或比對失敗時編修仍保留，請手動執行 `cvewatch match`
- **下載範本**、**匯出清冊**：另存新檔對話框（預設「文件」資料夾，檔名 `cvewatch-inventory-template.xlsx`、`cvewatch-inventory-YYYYMMDD.xlsx`），不覆蓋既有檔案；匯出內容與 `cvewatch asset export` 相同，檔案未加密
- **從 ISMS 清冊匯入**：選擇 ISMS 資訊資產清冊（.xlsx）後，視窗以與 `cvewatch asset import-isms --dry-run` 相同的內容顯示預覽（新增、更新、版本待補的元件數、略過的列與明細；既有資產逐欄列出 ISMS 欄位的新舊值），資料庫尚未變更；按「匯入」才寫入，完成後自動比對並重新載入。只更新 ISMS 欄位並加入版本待補元件，不會移除元件，也沒有退役選項。不是 ISMS 清冊時預覽顯示「找不到 ISMS 資訊資產清冊的表頭」。與「匯入清冊」相同，同資料夾找不到 `cvewatch.exe` 時按鈕停用（見[資產清冊](assets.md#由-isms-清冊建立資產)）
- **版本待補**：版本空白的元件不參與比對。清單在有版本待補元件的資產名稱後標示「（版本待補）」，詳情顯示「<產品> 版本待補（未納入比對）」，編輯對話框的版本欄以「版本待補」提示；在版本欄填上版本並儲存即開始比對，未修改的版本待補元件不影響儲存其他欄位。已有版本的元件不能清成空白，新加入的元件必須填版本。工具列的「只顯示版本待補」只列出有版本待補元件的資產；匯入預覽有版本待補的元件時以警告色提醒（見[資產清冊](assets.md#版本待補)）

## 啟動錯誤與 CLI 專用功能

啟動錯誤：資料庫尚未建立、Credential Manager 中沒有資料庫金鑰或設定檔有誤時，視窗會顯示原因與對應的指令（例如 `cvewatch init`、`cvewatch db import-key`），按「關閉」後結束。設定檔有未知欄位時照常開啟，頂端以黃色警告列顯示。

仍只在 CLI 提供：`cvewatch init`、`cvewatch db export-key | import-key | rekey | backup | restore`、`cvewatch schedule status | uninstall`、`cvewatch asset import-packages`（主機套件清單）、`cvewatch vex import`。
